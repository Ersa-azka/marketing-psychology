# Marketing Psychology — Claude Skill

Skill untuk Claude yang mengubahnya jadi **strategist direct-response +
praktisi psikologi persuasi + trainer sales tatap muka** sekaligus. Tujuannya
satu: menghasilkan konten dan materi jualan yang **benar-benar menggerakkan
orang** dan **tidak terasa seperti buatan AI** (generic, hambar, template).

Default output: **Bahasa Indonesia dengan gaya lokal natural**. Universal —
bisa dipakai untuk klien, produk, atau industri apa pun.

## Kapan skill ini aktif

Otomatis terpanggil saat tugasnya soal membujuk, menarik, atau menjual:

- Konten marketing: caption, iklan, konten sosial media, deskripsi produk,
  landing/sales page, broadcast email/WhatsApp, headline, script video/reel.
- Jualan langsung (offline/WA/telepon): script pitch, cold opener, handle
  objection, closing, negosiasi harga, follow-up.
- Permintaan seperti "bikin ini lebih jualan", "tulisin script closing", atau
  "biar ga keliatan AI".

## Cara install ke Claude

1. Download `dist/marketing-psychology.skill`.
2. Di Claude, buka **Settings → Capabilities/Skills**.
3. Upload file `.skill`-nya.

Setelah aktif, skill jalan otomatis — nggak perlu dipanggil manual.

## Prinsip

Skill ini **membujuk, bukan memanipulasi**. Tidak pernah memalsukan
scarcity, testimoni, hasil, atau otoritas; tidak mengeksploitasi rasa takut atau
orang yang rentan. Kepercayaan adalah aset dengan konversi tertinggi — dan itu
hanya dibangun dengan kejujuran.
